Blue Blood Mark Implementation Plan

Goal: Ship Blue Blood as rung 2 of the Mark ladder, replacing the dropped Pulse, by tinting the noise ink slate blue.

Architecture: The noise ink is already a parameter of CodeRenderer.paths, so the Mark is a colour selection and nothing more -- the same shape as Vein, Halo and Crown. Palette gains a second five-entry table; MarkRenderer picks between the two by rung; Renderer routes the existing call through it. The JS reference renderer mirrors every value, and the differential test holds the two byte for byte.

Tech Stack: Solidity 0.8.35 (Foundry, via_ir), Node 24 with node --test.

Global Constraints

  • Plain ASCII only in all docs and code comments.
  • Every colour constant MUST exist identically in contracts/src/render/ and tools/render-token.mjs; Renderer.t.sol diffs the two renderers.
  • The luminance match is not negotiable: |luma601(heart) - luma601(noise)| <= 1 at every rung, for BOTH palettes.
  • New rule: with Blue Blood worn, chroma(noise) < chroma(heart) at every rung.
  • Generated files carry // GENERATED by tools/<script> and are never hand-edited.
  • forge build --sizes must show positive runtime margin before done.
  • Foundry needs export PATH=$HOME/.foundry/bin:$PATH; Node needs source ~/.nvm/nvm.sh.

Task 2: The Mark, the selector, and the wiring

Files:

  • Modify: contracts/src/render/MarkRenderer.sol, Renderer.sol
  • Modify: tools/render-token.mjs
  • Test: contracts/test/MarkRenderer.t.sol

Consumes: Palette.bluebloodAt from Task 1. Produces: MarkRenderer.BLUEBLOOD, MarkRenderer.noise(marks, rung).

  • Rename the PULSE bit to BLUEBLOOD at the same bit position (rung 2, price 5) and change names() to emit blueblood.
  • Add noise(uint256 marks, uint256 rung) returning Palette.bluebloodAt(rung) when worn and Palette.noiseAt(rung) when not.
  • Route Renderer.svg through it in place of the bare Palette.noiseAt.
  • Mirror both in tools/render-token.mjs.
  • Run both suites; the differential test must still pass for unmarked tokens, proving nothing moved for a token without the Mark.
  • Commit.
