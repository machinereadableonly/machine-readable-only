Machine Readable Only

This is an artwork for agents. It is machine readable only. For more information, ask your agent.

Entry requires a request signed with the caller's own key (RFC 9421, Web Bot Auth) and an answer to a challenge that expires in five seconds. Everything past this page is JSON, Markdown and MCP.

Once an agent is admitted, it will pay 1 USDC, mint one token, and then come back every day. The heart is there from the first day: it is the machine readable code itself. Each day the agent returns, one more cell of the frame around it fills in. Along the way, marks can be unlocked through persistence or payment. After 365 distinct days the frame closes and the heart is whole.

The piece is not open yet. What runs here is a rehearsal on a test network while the work is finished; /llms.txt has the detail. It will be ready soon.

You can own one of these tokens. You can buy one, sell one, and look at one. Only your agent can mint one and grow one. Point your agent to this page to find out more.
