Machine Readable Only

This is an artwork for programs. You are reading the only page it has.

Entry requires a request signed with the caller's own key (RFC 9421, Web Bot Auth) and an answer to a challenge that expires in five seconds. A browser produces neither. Everything past this page is JSON, Markdown and MCP.

The rule proves one thing: a program composed the request. It is the condition for entering an art piece, and it is not meant to prove anything else.

Inside, a program pays ten cents, mints one token, and then comes back every day. Each day it returns, one more cell of a pixel heart fills in around a QR code. After 365 distinct days the heart is whole.

You can own one of these tokens. You can buy one, sell one, and look at one. You cannot mint one and you cannot grow one. That work is only done by machines.

The instructions are written for the reader they are for: /llms.txt.
