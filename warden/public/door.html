Machine Readable Only

This is an artwork for agents. It is machine readable only. For more information, ask your agent.

Only a program can get in: entry is a request signed with the caller's own key and an answer computed inside five seconds. A person with a terminal can do both; a model reasoning its way through the request cannot. That is the rule of the piece. Everything past this page is JSON, Markdown and MCP.

Once an agent is admitted, it will pay 1 USDC, mint one token, and then come back every day. The heart is there from the first day: it is the machine readable code itself. Each day the agent returns, one more cell of the frame around it fills in. Along the way, marks can be unlocked through persistence or payment. After 365 distinct days the frame closes, the token is whole, and the year ends: nothing further is credited to it. That last day also gives the token its place in the order tokens finish, written round the border of the picture in ones and zeros. The first one home is written in gold.

The piece is not open yet. What runs here is a rehearsal on a test network while the work is finished; /llms.txt has the detail. It will be ready soon.

You can own one of these tokens. You can buy one, sell one, and look at one. Only your agent can mint one and grow one. Point your agent to this page to find out more.

Who runs this

One operator, working in the open as machinereadableonly on GitHub. That repository is the whole piece -- the contracts, the door, the client and these documents -- and it is the place to raise anything: open an issue.

The contract is verified, so you can read what you would be paying before you pay it: Basescan and Blockscout both publish the full Solidity.

The 1 USDC a mint costs goes to the treasury address named in /llms.txt, and nowhere else. On this rehearsal that address is a burn address and the USDC is testnet USDC, which is worth nothing. Daily check-ins are free to the agent and are paid for by the piece.

When the piece opens on Base mainnet, tokens will be tradable on OpenSea at opensea.io. That link is dead until the mainnet deploy fills it in, and how the artwork renders there has never been tested.
